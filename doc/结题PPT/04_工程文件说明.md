## 一、工具类型与技术栈

| 层 | 选型 |
|---|---|
| 后端框架 | FastAPI + Uvicorn（异步 Web 服务，SSE 流式） |
| 数据校验 | Pydantic v2（贯穿 IR / Chunk 全流程，Schema First） |
| 关系数据库 | SQLite + FTS5 全文索引（aiosqlite 异步驱动） |
| 向量数据库 | Qdrant 本地文件模式（无需 Docker，单进程文件锁） |
| 文档解析 | MinerU 在线 API（`/api/v4` 批量精准解析，vlm 模式） |
| 嵌入 / 重排 / 视觉 | 阿里云百炼 DashScope（text-embedding-v4 / qwen3-rerank / qwen-plus 多模态） |
| 问答大模型 | 多 Provider 可一键切换（默认 qwen-plus；可切 DeepSeek V4 / GPT-5.5 / Kimi K2.6），openai SDK |
| HTTP 客户端 | httpx |
| 后端包管理 | **uv**（替代 pip + venv） |
| 前端框架 | React 19 + Vite 7 + TypeScript（strict） |
| 前端样式 / 组件 | Tailwind CSS v4（`@theme inline`）+ shadcn/ui |
| 前端路由 / 动效 | React Router v7 + framer-motion |
| Markdown / PDF | react-markdown + remark-gfm；react-pdf（bbox 高亮溯源） |
| 前端包管理 | npm |
| 代码质量 | basedpyright（类型）、ruff（lint/format）、ESLint、tsc |

## 三、工程组成结构与源文件—模块对应

### 3.1 后端 `backend/app/`（分层架构）

```
adapters/        MinerU 输出 → 标准化 IR（模块二）
  bundle_parser.py     解压 MinerU zip，识别 content_list_v2.json / layout.json / origin.pdf / images
  normalizer.py        Raw MinerU Block → 标准 IRBlock（宽松容错，块类型归一化）
  dom_builder.py       重建文档 DOM 树，注入 header_path 标题路径
  footnote_linker.py   脚注关联
  format_checker.py    MinerU 输出格式严格审计（19 项语义校验，格式漂移监控）

api/             FastAPI 路由层（模块一/四/五/六/七/九）
  health.py            健康检查
  kb.py                知识库 CRUD + 文件夹同步
  documents.py         上传 / 解析触发 / 删除 / origin-pdf / raw-text / index-text
  chat.py              流式问答（SSE）/ 纯检索 / 检索 trace
  conversations.py     多轮会话 CRUD + 流式发送 + Fork
  course_info.py       模块九：课程信息卡片生成（含 stream Agent）+ 问答
  review.py            模块七：课后复盘讲义生成 / 保存 / 追问 / 导出 PDF
  settings.py          提示词管理 + 用户配置（API Key / 模型）
  tasks.py             任务状态查询

chunkers/        结构感知切片（模块三）
  parent_chunker.py    父块切片（按 N 级标题聚合，空标题合并）
  child_chunker.py     子块切片（句界滑动窗口，原子块保留，header_path 前置）

enrichers/       多模态富化（模块三）
  enricher.py          图片 VLM 描述 / 表格摘要 / 代码 / 公式 LLM 富化（检索用文本）

models/          Pydantic 数据模型
  models_raw_mineru.py MinerU 原始输出 Schema（宽进）
  models_ir.py         自研 IR 中间格式 Schema（严出）
  models_chunk.py      Parent / Child Chunk Schema

prompts/         外置提示词模板（11 个 .md，支持热重载）
  query_plan_system.md           检索查询规划
  doc_tree_system.md             LLM 文档树重建
  index_summary_system.md        父块摘要索引
  index_hypo_question_system.md  推测问题索引
  rag_eval_system.md             RAG 检索完整度评估（Agent）
  course_info_extract_system.md  课程信息结构化抽取
  course_info_eval_system.md     课程信息完整度评估（多轮检索 Agent）
  course_info_chat_system.md     课程信息问答
  lecture_review_section_first.md / _subsequent.md  讲义生成（首节 / 后续节）
  lecture_review_followup_system.md                 讲义追问

services/        业务服务层（核心算法集中地）
  pipeline_service.py       全流程编排（上传→解析→IR→切片→索引，16 步）
  mineru_client.py          MinerU API 客户端（v4 批量精准解析）
  normalizer/doc_tree_service.py  LLM 文档树重建服务
  embedding_service.py      text-embedding-v4 向量化
  index_service.py / index_builder_service.py  Qdrant + SQLite FTS5 入库
  cn_tokenizer.py           jieba 中文分词（修复 FTS5 中文零召回）
  query_planner.py          LLM 查询规划（关键词 + HyDE 语义查询）
  retrieval_service.py      混合检索 + RRF 融合
  rerank_service.py         qwen3-rerank 重排序
  retrieval_trace.py        检索全链路结构化 trace（驱动"检索透视"）
  qa_service.py             多 Provider 流式问答 + stream_llm_completion

  course_info_service.py    模块九：课程信息提取 + 多轮检索 Agent + 截止日解析
```

## 四、运行环境（含条件）

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（本地运行） |
| Python | 3.11+，包管理 **uv**（非 pip） |
| Node.js | 20+ |
| 浏览器 | Chrome / Edge 120+ |
| 向量库 | Qdrant 本地文件模式（自动初始化，单进程文件锁） |
| 关系库 | SQLite + FTS5（内置，自动建表） |
| 网络 | 需访问外网调用 MinerU、阿里云百炼 API |
| 必填 API Key | `MINERU_API_KEY`（解析）、`ALIBABA_CLOUD_ACCESS_KEY_SECRET`（嵌入/重排/VLM） |
| 可选 API Key | `QA_BASE_URL` + `QA_API_KEY` + `QA_MODEL`（切换问答 Provider） |

> 无 API Key 也能启动服务，但真机解析 / 问答不可用；静态分析、前端构建、不依赖真实 API 的逻辑仍可验证。

## 五、如何运行

### 1. 后端（在 `backend/` 下）
```bash
uv sync                                  # 安装依赖（创建 .venv）
cp .env.example .env                     # 配置环境变量，填入两个必填 Key
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
启动后自动创建 `data/` 下所有目录、初始化 SQLite（含全部表）与 Qdrant 向量集合。

### 2. 前端（在 `frontend/` 下）
```bash
npm install
npm run dev          # 默认 http://localhost:5173，已配置 /api 代理到后端
```

### 3. 访问
浏览器打开 `http://localhost:5173`。
基本流程：新建知识库 → 上传文件 → 触发解析 → 解析完成后开始对话 → 查看引用与三套可视化透视。

### 4. 质量检查（可选，供老师复现）
```bash
# 后端类型检查（仓库根运行）
uv run --project backend basedpyright
# 前端类型检查（必须指定 tsconfig.app.json）
cd frontend && npx tsc -p tsconfig.app.json --noEmit
# 后端回归测试（运行前需停掉 uvicorn —— Qdrant 单进程文件锁）
cd backend && uv run python test_v120.py && uv run python test_v140.py
```
