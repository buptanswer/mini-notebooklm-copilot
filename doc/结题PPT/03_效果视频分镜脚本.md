# 效果视频分镜脚本（≤ 2 分钟）

> 老师硬要求：效果视频**单独成文件、原则上不超过 2 分钟**，展示软件工程、运行及效果，且**运行效果要与设计任务目标相对应**。
> 本脚本按"一个问题揭示整条隐藏链路"的主线设计，把项目最能体现难度的**三套可视化透视**作为主战场。
>
> 录制建议：1080p、屏幕录制（OBS / Win+G）；提前把数据准备好（用你的"程序设计基础实训"课程文件夹），避免现场等解析；旁白可后期配音或加字幕；全程**不要露出 API Key / 设置页明文**。

---

## 总时长分配（目标 110 秒，留 10 秒缓冲）

| 镜头 | 时长 | 内容 | 对应设计目标 |
|---|---|---|---|
| 0 | 0–8s | 标题卡 + 一句话定位 | 课题名称 |
| 1 | 8–22s | 知识库工作台总览 + 文件管理 | 通用底座 / 模块六 |
| 2 | 22–42s | **解析透视**：文档树 + 坐标画布 | 难点一（IR 重建） |
| 3 | 42–62s | 问答：流式回答 + 引用溯源 + 点来源跳解析透视 | 难点二/三 + 溯源 |
| 4 | 62–82s | **检索透视**：六阶段动画 | 难点三（混合检索） |
| 5 | 82–100s | **课程管家 Agent 决策透视**：多轮检索时间线 | 难点四（Agent） |
| 6 | 100–110s | 课后复盘流式生成讲义 + 收尾卡 | 模块七 + 收束 |

## 分镜详情

### 镜头 0 · 标题卡（0–8s）
- 画面：黑/米白底，居中打出 `Mini-NotebookLM —— 面向大学生的多模态课程知识库与 AI 辅导系统`，副标题 `李宇 2022210347`。
- 旁白：「这是 Mini-NotebookLM，一个本地运行、能把课程资料变成可检索 AI 知识库的系统。」

### 镜头 1 · 工作台总览（8–22s）
- 操作：从知识库首页（书架卡片）点进一个课程 KB → 展示 Explorer 风格文件管理（表格、状态列、右键菜单一闪）。
- 旁白：「上传课程的 PDF、PPT、讲义后，系统自动解析入库。我们先看它背后做了什么。」
- 提示：鼠标移动要慢、稳；右键菜单点出来停 1 秒即可。

### 镜头 2 · 解析透视（22–42s）★难点一
- 操作：双击一个已索引文档 → 进入**解析透视**。左边文档树缓缓展开；中间 PDF 画布上 MinerU 识别块的 bbox 高亮；点一个块 → 右侧检视面板显示块类型/内容/所属父块/VLM 描述。
- 旁白：「MinerU 返回的结构是扁平的，我用大模型重建出真实的文档树，并保留了坐标锚点 —— 每个识别块、每个父块都能点开看。」
- 提示：突出"文档树"和"点击块高亮"两个动作。

### 镜头 3 · 问答 + 溯源（42–62s）★难点二/三
- 操作：进入问答页，输入一个能命中图/表的问题 → 流式回答逐字出现 → 右侧引用面板显示来源（章节路径 + 页码 + 相关性分数）→ 点某条来源的"解析透视"→ 跳转并高亮命中的版面块。
- 旁白：「提问后，回答会带引用溯源。点任意一条来源，能直接跳回它在原文里的位置 —— 不是凭空生成，每句话都有出处。」

### 镜头 4 · 检索透视（62–82s）★难点三
- 操作：在问答页点顶栏"透视检索"→ 进入**检索透视**六阶段动画：查询规划 → 关键词扫描 → 向量空间寻邻 → RRF 融合 → 重排连线 → Top-K。
- 旁白：「这一步通常是黑盒。我把它摊开：大模型先规划检索词，再走向量和关键词两路召回，融合后重排序 —— 全程动画可见。」
- 提示：这是最"唬人"的镜头，让动画完整跑一遍，节奏可以稍慢。

### 镜头 5 · 课程管家 Agent 决策透视（82–100s）★难点四
- 操作：进入**课程管家** → 点"生成卡片"→ 右侧 **Agent 决策透视**时间线流式展开：首轮检索 → 完整度评估（缺口分析气泡）→ 第二轮补检索 → 收敛 → 生成课程信息卡片。
- 旁白：「课程管家是个多轮检索 Agent，它会自己评估信息够不够、对缺失项再查一轮，最后整合成课程信息卡片。」

### 镜头 6 · 课后复盘 + 收尾（100–110s）
- 操作：课后复盘页选日期 → 流式生成"老师口吻"的逐节讲义（快进/截取开头几秒）→ 切到收尾卡。
- 收尾卡：`通用底座 + 场景 Agent + 可视化透视　|　单人 · 2.4 万行 · 8 版迭代　|　谢谢观看`
- 旁白：「课后复盘能基于课堂录音自动生成讲义。以上就是 Mini-NotebookLM 的核心能力，谢谢观看。」
