# 文档导览

本目录采用「**当前情况 → 开发目标 → 实施手册**」三件套滚动维护。接手开发时按这个顺序读即可建立全局认知。

## 三件套（每轮开发都要更新）

| 文档 | 作用 | 一句话 |
|------|------|--------|
| [项目当前情况.md](./项目当前情况.md) | 项目此刻**已实现到什么程度** | 必须与代码一致的交接文档；先读它 |
| [下一步开发目标.md](./下一步开发目标.md) | 项目**要做成什么样** | 完整需求规格 / 蓝图（含尚未实现的提升项：模块八、音视频转写） |
| [开发实施手册.md](./开发实施手册.md) | 从当前情况到目标**怎么一步步做** | 让能力一般的接手者也能照本宣科；当前内容覆盖 v1.1.0→v1.2.0 那一轮 |

## 维护约定

- **每轮开发完成后**：更新三件套 + 根目录 `README.md` + `RELEASE_NOTES.md`。
- **MinerU API 出现未知 / 错误字段**：更新《在线API输出文件格式（SaaS推断版）》，并同步 `backend/app/adapters/normalizer.py` + `format_checker.py` 的已知字段集合（漂移信号来自 `data/format_probe_log.jsonl` 增长）。
- **解析 / 入库工作流变化**：更新《MinerU to RAG Pipeline 架构设计与数据流方案》。
